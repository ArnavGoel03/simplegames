## Candidates rejected or bounded

- HTML CSP and DENY headers are present on live pages; absence on sw.js is not
  evidence that HTML protections are missing.
- JSON-LD escapes markup; unknown legal slugs return 404; no user-input HTML sink.
- Missing Charade art and null governing jurisdiction are documented choices.
- The unsafe-inline CSP is an explicit static-render tradeoff on a site without
  user input; a nonce rewrite was not justified.
- npm audit reports two production dependency entries (Next and sharp). The
  named Next advisories require Windows hosting or the AVIF image optimizer;
  this site uses Cloudflare and disables image optimization. The sharp advisory
  concerns libheif decoding, with no user image upload or HEIF decoding path here.
  No reachable exploit was established; dependency replacements were not mixed
  into this defect patch.
- Invalid generic shuffle counts above 256 do not occur in production callers,
  which use the frozen 52-card deck. No speculative API change was made.
