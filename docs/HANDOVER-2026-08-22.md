## 2. The names, and which layers moved

| Was | Is | Layer |
|---|---|---|
| Simple Games | Glass Table Games | studio, display |
| Chaupal | Circuit | game, display and subdomain |
| Taash | Deal | card room, display and subdomain |
| Draw | Charade | game, display and subdomain |
| Lattice | Lattice | unchanged, and the name the others were measured against |

The rule, which Lattice set and nobody had written down: **one ordinary English
word naming the structure of the game, not its category.** A circuit is what both
board games are. A deal is what all eight card and patience games begin with. A
charade is the game where "Draw" was only the input to it.

**What deliberately did not move, and must not be tidied:**

- **Worker names.** `chaupal-games`, `taash`, `lattice-games`, `draw-games`,
  `chaupal-realtime` all keep their old names. A Worker stopped being an address
  the day the studio got a domain. More seriously, see §4.
- **Game ids.** `GAMES.chaupal.id` is still `"chaupal"`. An id is a key that
  storage and the archive record; a name is a label.
- **`NAMESPACE`**, which is `"glasstable"` and frozen. See §4.

## 4. Traps. Read this section before touching anything

**The shared checkout is on a branch.** As of 22 August, `~/dev/chaupal` is on
`feat/manifest-headless`, eight commits behind `origin/main`. Anything built
there ships stale code. `git status -sb` prints the branch on line one;
`git status --porcelain` omits it, which is how a site got deployed from that
branch. **Check the branch before any build you intend to ship.**

**Three to five Claude sessions work in that one tree.** Never `git stash`,
never `git add -A`, stage by explicit path, commit immediately, and to move a
commit to another branch use `git worktree add` on a scratch path rather than
switching the shared checkout.

**`NAMESPACE` must never follow a rename.** It is the prefix in every session
cookie, saved appearance and token audience. It reads as the studio rather than
a game, so a careful edit leaves it alone, and a find and replace over a game
name takes it and signs everybody out.

**`chaupal-realtime` owns Durable Object storage.** Renaming that Worker does
not move a room, it starts a second Worker with nothing in it. `RoomDO` and
`DrawRoomDO` cost a reconnect. `EpochDO` holds the key `deriveServerSeed` takes
as input, so stranding it means every commitment published under the open epoch
could never be revealed: not lost session state, a broken promise. `epoch.ts`
already refuses to regenerate that key for the same reason. Moving it needs a
`transferred_classes` migration written deliberately, and **no check in the
repository can see it go wrong**, because a stranded room looks exactly like a
room nobody opened.

**The derivation tags are frozen now.** They were rotated once, on 19 August,
while the archive held two games and both had a null `fairness` column, so
nothing verified differently. That window is closed; changing them again breaks
every published proof. `pnpm --filter @play/db check-archive-epoch` counts
transcripts predating a cutoff.

**Common English words as names cost something.** `docs/FUTURE.md` §10 in the
monorepo. Adding "Deal" to `NEVER_TRANSLATED` broke the catalogue check in four
languages, because it matches by substring and flagged the UI phrase "Deal me
in". Game names never reach a catalogue, so they do not belong on that list.

**A stale DNS negative cache looks exactly like a broken zone.** Query
`1.1.1.1` directly before reporting a hostname as missing, and test a poisoned
host by requesting its IP with an explicit `Host` header and SNI.

## 5. Bugs found, and how they were found

Both were found by looking at what shipped, not by a failing test.

**A drag lifted the whole column.** `cards.slice(-Math.max(1, carrying))` is
correct for every number and catastrophic for one non-number: `Math.max(1,
undefined)` is `NaN` and `slice(-NaN)` is `slice(0)`, the entire pile. The
engine was never wrong, `moveError` refuses anything that is not a descending
alternating colour run, so only the picture lied. Fixed by clamping.

**The trademark clause named a game that no longer existed** and named none of
the ones in use, weeks after the rename, because it was written out rather than
derived. It reads the registry now.

## 6. Open, in the order I would take them

1. **`gondilalsaraf.com` is serving `402 DEPLOYMENT_DISABLED`** to a real shop's
   customers. Registrar is Name.com, nameservers are `ns1/ns2.vercel-dns.com`,
   and the Vercel account is soft blocked account wide. The fix is to rebuild it
   as a Cloudflare Worker and repoint the nameservers, the same path the five
   studio sites now use. The registrar being independent is what makes this
   recoverable. **This is the only thing broken for an actual person.**

2. **The studio has no visual identity.** Five sites that do not look related:
   the studio is indigo on cool paper, the games are warm dark brown, and
   nothing carries across but a footer line. Arnav's words were "soulless" and
   "no method to the madness". This is a design project needing a brief, not a
   CSS pass, and it is the most valuable open item after Gondilal.

3. **Game feel.** Patience now deals; nothing else animates. Wanted: cards that
   fly rather than teleport, a lift and shadow under a dragged stack, a snap on
   a legal move and a refusal on an illegal one, a win sequence, sound, haptics.
   One constraint to know before promising it: **`navigator.vibrate` does not
   exist in Safari on iOS**, so haptics are Android only and iOS needs sound and
   motion instead.

4. **Setup screens still read as a phone column on a desktop.** The width fix
   was a stopgap. The real answer is a layout that uses the width, explanation
   one side and controls the other.

5. **Draw, now Charade, has no real art on the studio site.** The `GameArt` rule
   requires a capture of the real thing, and a Draw room shows an empty canvas
   until a second player joins, so it needs two browsers to photograph.

6. **`hello@glasstablegames.com` does not exist.** Seven live legal documents
   name it. Cloudflare Email Routing is free and inbound only; sending as that
   address needs Zoho's free tier or an SMTP relay.

7. **`feat/manifest-headless` wants merging or deleting**, and the shared
   checkout wants returning to `main`.
